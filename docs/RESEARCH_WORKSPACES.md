# Statistical validation, 3D measurements and molecular evidence

Use the Image & ROI, 3D workspace, Validation and Molecular evidence buttons to switch workspaces. ROI/processing choices are retained while switching.

## Validation workspace

Numeric reference checks compare Pearson and Spearman with SciPy, and thresholded Manders with hand-derived examples. These are engineering checks. Independent Fiji comparisons and biological control experiments remain pending. Existing ROI results are not certified for publication.

Sensitivity comparisons apply the same XY ROIs to raw and processed data, with identical manually specified thresholds, or zero thresholds when manual mode is not selected. Automatic thresholds are intentionally excluded. The report contains both sets of complete ROI results and processed-minus-raw differences in correlation and overlap measurements. FWHM sensitivity is not yet included in this report.

The spatial control tests one ROI/channel pair at a time. Channel B is translated over the entire source XY plane, with periodic wraparound; channel A and the ROI remain fixed. This preserves the translated channel's spatial structure on the torus rather than independently shuffling pixels. It assumes translation invariance across the field and an independently chosen ROI. Heterogeneous compartments, cell boundaries, selection based on observed overlap, and nonperiodic gradients can invalidate this model. The app requires the user to assess its applicability; it does not automatically establish it from the image.

All nonidentity translations are enumerated when the group is small enough. Otherwise translations are sampled uniformly with replacement using the recorded NumPy seed. The one-sided upper-tail result is `(exceedances + 1)/(shifts + 1)`, counting ties within an absolute 1e-12 tolerance. The identity contributes the observed statistic. Null correlations, quantiles, actual shift count, seed, input ROI, source SHA-256, calibration and processing recipe are exported. Constant observed/translated subsets produce an explicit error rather than discarded null draws. Requests are bounded to 25 million ROI pixel comparisons. This is one unadjusted conditional spatial test, not experiment-level inference, a binding probability, or a replacement for biological replicates. Multiple testing adjustment, alternative compartment-preserving nulls and experiment-level uncertainty remain future work.

See [SciPy's discussion of randomized tail calculations](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.permutation_test.html) for the add-one convention. The app implements translations, not SciPy's pixel permutations.

## Linked sections and 3D regions

The 3D preview tab includes linked XY, XZ and YZ source sections. Crosshair sliders or clicks update the shared source coordinates. XZ/YZ decode source planes at full resolution, then generate bounded display thumbnails; quantitative data do not come from those thumbnails. All three sections use the selected XY plane's channel contrast ceilings. A change in Z can therefore change their display contrast, without changing measurements.

Physical section proportions use X/Y/Z metadata only when all three calibrations exist. Otherwise voxel proportions are explicitly labelled. Z stretch affects only section display. Crosshairs refer to pixel/voxel centers; the orange rectangle marks inclusive cuboid voxel bounds. It is a projection of the cuboid bounds, not the boundary of a segmented organelle. The VTK volume renderer is still a separate bounded preview; it does not yet display a clipping plane or cuboid overlay.

A cuboid can contain 3–500,000 source voxels. Measurements use original full-resolution planes, or an explicitly selected applied processing recipe. Processing happens on the full XY plane before cropping, preserving the same filter boundaries as 2D measurements. The resulting summaries include voxel count, calibrated *region* volume (when X/Y/Z are known), per-channel intensities, Pearson, Spearman and Manders. Default Manders thresholds are zero and are stated in the interface. These measurements do not quantify a segmented organelle volume or provide voxel-independent significance. Source hash, calibration, coordinates, recipe and application version are included in the separate JSON export. Results must be exported before changing image/session; they are not saved as a project yet.

## STRING and KEGG

These optional integrations send only explicitly entered/selected identifiers and public query parameters to the chosen database. Neither endpoint accepts images, measurements or conversations. The first implementation supports human (taxonomy 9606 / KEGG hsa) only and no LLM.

STRING is pinned to version 12.5. Identifier candidates must be selected explicitly before requesting a functional or physical association network. Queries return edges among selected proteins only, without extra neighbors. The requested minimum score uses STRING's 0–1000 request scale; result scores are displayed on the API's 0–1 scale. These are database association scores, not probabilities of binding in a microscopy experiment. Evidence component scores are shown when returned. No STRING outputs are bundled with the installer.

KEGG searches return candidate human genes (exact identifier/alias matches are sorted first before the display cap, without automatic selection); users select one gene before retrieving pathway memberships. Only the small human pathway-name catalogue is cached to label memberships; no whole-organism gene database is downloaded. The output is bounded to 25 candidates/pathways, with names resolved for the first 10 pathways; remaining IDs remain usable. These are membership lookups, not enrichment, activation or perturbation predictions. Official KEGG PNG pathway diagrams can be requested explicitly from a pathway row, viewed with zoom/scroll controls and reopened from the local cache. No KEGG maps or data are redistributed in this repository or installer. Diagram colours are reference annotations, not inferred experimental activation. The panel is restricted to academic research use, consistent with the user's intended deployment. A future commercial product would require separate review of KEGG access terms/licensing.

HTTPS certificate verification uses the bundled certifi CA roots for consistent macOS/Windows operation. Calls are globally serialized with at least 1.05 seconds between starts (more conservative than KEGG's limit). Text responses are bounded to 1 MiB; PNG pathway diagrams to 4 MiB and 16 megapixels. Diagrams are validated as PNG before caching, and their hashes are checked on cache reuse. Cache storage is limited to 64 entries and 64 MiB including metadata. Queries use a seven-day freshness window. Offline-only mode makes no network requests, can reuse older cache entries with explicit stale labels, and fails clearly on a missing exact query. Records preserve the full provider URL, retrieval timestamp, raw-response SHA-256 and database version. Corrupted cache content is not reused. Lookup and result JSON exports include query parameters, provenance, citation links and interpretation limitations. Cache files are local and excluded from Git.

No API key is required for the selected STRING mapping/network and KEGG find/link/list endpoints. The user must explicitly initiate lookups. Failures do not silently switch providers, send additional data or substitute model-generated evidence. Source links open only approved HTTPS database domains in the desktop app.

References: [STRING API](https://string-db.org/help/api/), [STRING access and licensing](https://string-db.org/cgi/access?footer_active_subpage=licensing), [KEGG API and academic restriction](https://www.kegg.jp/kegg/rest/), [KEGG API manual](https://www.kegg.jp/kegg/rest/keggapi.html).

## Pathway-diagram records

The diagram dialog shows native image dimensions, original retrieval time and online/cache/stale status, and links to the original PNG and interactive KEGG map. Evidence JSON exports include the last viewed diagram provenance, without embedding the image bytes. The cache is shared with identifier lookups and uses the same academic-use gate, rate limiting and offline-only behavior. Provider errors remain visible; no substitute diagram is generated. Closing the diagram returns to the pathway table.
